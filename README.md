# 🐾 わんわんクイズ＆ポケット犬種図鑑 🐾

このアプリは、インターネット上の犬のデータを提供する「DogAPI」を使った、かわいい**犬種当てクイズゲーム**と**コレクション式ポケット犬種図鑑**の統合アプリケーションです。
クイズで遊んで正解数を重ねることで、少しずつ図鑑の紹介文や豆知識が解放されていきます！

---

## 🎮 遊び方

### 1. ゲームモード
* **4択クイズ (10問)**: 表示される犬の写真を見て、4つの選択肢から正しい犬種を選びます。
* **2択タイムアタック (10問)**: 最初に指定された「お題の犬種」の写真を、左右（または上下）に表示される2枚の画像からすばやく見つけ出すモードです。間違えるとペナルティタイム（+3秒）が加算されます。
* **2択エンドレス (1問3秒)**: 1問3秒 of 制限時間内に、2枚の写真から指定された犬種を正解し続けるスリリングなモードです。1度でも間違えるか、時間切れになるとゲームオーバーです。
* **激似2択対決 (10問) ⚔️**: 柴犬と秋田犬、ゴールデンとラブラドールなど、見た目が極めて似ているペアだけで構成された超高難易度の2択タイムアタックモードです。

### 2. 難易度のちがい
* **かんたん**: ランダムに他の犬種が選択肢として登場します。
* **むずかしい (見た目が似た犬種)**: 「柴犬」がお題のときは「秋田犬」や「ハスキー」など、見た目の特徴が似ている犬種が優先的にダミーの選択肢として登場します。

### 3. おやつ（ヒント）をあげる 🍖
4択クイズの「むずかしい」モードでは、おやつボタンを最大3回まで押すことでヒントをもらえます。
* **1〜2回目**: ハズレの選択肢が1つずつ消えていきます。
* **3回目**: 画面に犬種の「頭文字ヒント」が表示されます（ハズレは2つ消えたまま、残り2択の状態で推理できます）。
（※おやつを多くあげるほど、正解したときにもらえるポイントは少なくなります）

### 4. ポケット犬種図鑑 📖
クイズで一定の成績を収めることで、その犬種の図鑑ページが解放されていきます！
* **段階的な解放**:
  * **正解1回**: カタカナ名とカラー写真が解放され、図鑑から直接タイムアタックの練習ができるようになります。
  * **正解2回**: その犬の「原産国」「大きさ」、および「似ている犬種」の項目が解放されます。
  * **正解3回**: その犬のくわしい解説（日本語の豆知識）が読めるようになります。
* **成績による一発全解放 (ボーナス) 🏆**:
  以下の好成績を収めると、正解回数にかかわらず**一気に段階3まで全解放**されます！
  * 4択クイズ（むずかしい）で、おやつ（ヒント）の使用を1回以下に抑えて（スコア8点以上で）正解したとき。
  * 2択タイムアタックを20秒以内でクリアしたとき。

## ✨ v2.0.0 で追加された新機能

1. **過去のクリア記録（履歴）機能**: スタート画面から遷移でき、各ゲームのクリア成績や自己ベスト（最新20件）を振り返られる「過去の記録」ページを新設しました。
2. **図鑑に「似ている犬種」の項目**: 図鑑で解放された犬種に、見た目が似ている他の犬種リストを表示するようになりました。
3. **おやつヒントの調整**: おやつをあげる上限を3回に変更し、3回目に頭文字を表示。選択肢を2択残して推理を楽しめるようにしました。
4. **成績による図鑑全解放**: 4択クイズで8点以上で正解するか、タイムアタックを20秒以内でクリアすると一気に図鑑が全解放されます。
5. **激似2択対決モード**: 柴犬と秋田犬など、そっくりな組み合わせのみで遊べる超高難易度モードを追加しました。
6. **その他のUI改善**: カウントダウンの崩れ防止や、スマホでの2択画像の高さの1.5倍（225px）への拡大、効果音設定エリアの最下部への移動などを行いました。

1. **効果音（音量・ミュート）設定**：スタート画面で効果音のオン/オフや音量のスライダー調整ができるようになりました。
2. **可愛い中断ポップアップ**：クイズを中断する際、ブラウザの警告ではなくアプリの世界観に合わせた可愛い肉球デザインの確認画面が出るようになりました。
3. **データ管理（バックアップ）機能**：図鑑画面の下部から、セーブデータをテキストとしてコピーして保存したり、貼り付けて復元（インポート）したりできるようになりました。
4. **2択クイズのレスポンシブ表示**：パソコンなどの横長画面では画像が左右（横並び）に、スマホの縦長画面では上下に自動で綺麗に並ぶようになりました。

## 🚀 アプリの起動方法

1. このプロジェクトのフォルダ（`DogCollection`）でターミナルを開きます。
2. 以下のコマンドを実行して、ローカルサーバーを起動します：
   ```bash
   npm run dev
   ```
3. ブラウザでターミナルに表示されたアドレス（通常は `http://localhost:5173` または `http://localhost:8080` など）を開くと遊ぶことができます。

## 🧪 テストの実行

プログラムが正しく動いているかを検証する自動テスト（Playwright）を実行するには、以下のコマンドを使用します：
```bash
npx playwright test
```
