# 🐾 わんわんクイズ＆ポケット犬種図鑑 🐾

このアプリは、インターネット上の犬のデータを提供する「DogAPI」を使った、かわいい**犬種当てクイズゲーム**と**コレクション式ポケット犬種図鑑**の統合アプリケーションです。
クイズで遊んで正解数を重ねることで、少しずつ図鑑の紹介文や豆知識が解放されていきます！

---

## 🎮 遊び方

### 1. ゲームモード
* **4択クイズ (10問)**: 表示される犬の写真を見て、4つの選択肢から正しい犬種を選びます。
* **2択タイムアタック (10問)**: 最初に指定された「お題の犬種」の写真を、左右（または上下）に表示される2枚の画像からすばやく見つけ出すモードです。間違えるとペナルティタイム（+3秒）が加算されます。
* **2択エンドレス (1問3秒)**: 1問3秒の制限時間内に、2枚の写真から指定された犬種を正解し続けるスリリングなモードです。1度でも間違えるか、時間切れになるとゲームオーバーです。

### 2. 難易度のちがい
* **かんたん**: ランダムに他の犬種が選択肢として登場します。
* **むずかしい (見た目が似た犬種)**: 「柴犬」がお題のときは「秋田犬」や「ハスキー」など、見た目の特徴が似ている犬種が優先的にダミーの選択肢として登場します。

### 3. おやつ（ヒント）をあげる 🍖
4択クイズの「むずかしい」モードでは、おやつボタンを押すことでヒントをもらえます。
おやつをあげる回数に応じて、ハズレの選択肢が1つずつ消えていき、4回目には頭文字のヒントが表示されます。
（※おやつを多くあげるほど、正解したときにもらえるポイントは少なくなります）

### 4. ポケット犬種図鑑 📖
クイズで正解した回数に応じて、その犬種の図鑑ページが3段階で解放されます！
* **正解1回**: カタカナ名とカラー写真が解放され、図鑑から直接タイムアタックの練習ができるようになります。
* **正解2回**: その犬の「原産国」や「大きさ」が解放されます。
* **正解3回**: その犬のくわしい解説（日本語の豆知識）が読めるようになります。

## ✨ v1.9.0 で追加された新機能

1. **効果音（音量・ミュート）設定**：スタート画面で効果音のオン/オフや音量のスライダー調整ができるようになりました。
2. **可愛い中断ポップアップ**：クイズを中断する際、ブラウザの警告ではなくアプリの世界観に合わせた可愛い肉球デザインの確認画面が出るようになりました。
3. **データ管理（バックアップ）機能**：図鑑画面の下部から、セーブデータをテキストとしてコピーして保存したり、貼り付けて復元（インポート）したりできるようになりました。
4. **2択クイズのレスポンシブ表示**：パソコンなどの横長画面では画像が左右（横並び）に、スマホの縦長画面では上下に自動で綺麗に並ぶようになりました。

## 🚀 アプリの起動方法

1. このプロジェクトのフォルダ（`DogCollection`）でターミナルを開きます。
2. 以下のコマンドを実行して、ローカルサーバーを起動します：
   ```bash
   npm run dev
   ```
3. ブラウザでターミナルに表示されたアドレス（通常は `http://localhost:5173` または `http://localhost:8080` など）を開くと遊ぶことができます。

## 🧪 テストの実行

プログラムが正しく動いているかを検証する自動テスト（Playwright）を実行するには、以下のコマンドを使用します：
```bash
npx playwright test
```
